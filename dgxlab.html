01

System Check

เช็ก architecture, GPU, สิทธิ์ Docker และ Registry ก่อนติดตั้ง

COMMAND — copy / paste
uname -m
nvidia-smi --query-gpu=name --format=csv,noheader
sudo usermod -aG docker $USER && newgrp docker
docker ps >/dev/null && echo "Docker OK"
curl -fsSI https://registry.ollama.ai >/dev/null \
&& echo "Registry OK"
EXPECTED RESULT
aarch64 NVIDIA GB10 new shell, docker group Docker OK Registry OK
PASS newgrp เปิด shell ใหม่ — วางคำสั่งที่เหลือหลัง prompt ใหม่ · ต้องได้ครบ 5 รายการก่อนไปต่อ
02

Install Ollama

ติดตั้ง native บน DGX Spark และยืนยันว่า API พร้อม

COMMAND — copy / paste
curl -fsSL https://ollama.com/install.sh | sh
sudo systemctl enable --now ollama
systemctl is-active ollama
curl -s http://127.0.0.1:11434/api/tags
EXPECTED RESULT
active { "models": [...] }
PASS systemd = active และ Ollama API ตอบ JSON ที่มี key "models"
03

Pull & Test Gemma 4

ใช้ Ollama tag โดยตรง ไม่ต้อง convert model หรือสร้าง Modelfile

COMMAND — copy / paste
until ollama pull gemma4:26b-a4b-it-qat; do sleep 5; done
ollama list | grep gemma4
ollama run gemma4:26b-a4b-it-qat \
"Reply with exactly: GEMMA_OK" | grep GEMMA_OK
ollama ps
EXPECTED RESULT
gemma4:26b-a4b-it-qat ... GEMMA_OK ollama ps: ... 100% GPU ...
PASS โมเดลตอบได้ และ ollama ps แสดงว่า inference ใช้ GPU
04

Deploy Open WebUI

ใช้ Docker host network เพื่อเชื่อม Ollama ที่ 127.0.0.1:11434

COMMAND — copy / paste
docker run -d \
--network=host \
-v open-webui:/app/backend/data \
-e OLLAMA_BASE_URL=http://127.0.0.1:11434 \
--name open-webui \
--restart unless-stopped \
ghcr.io/open-webui/open-webui:main

docker ps --filter name=open-webui \
--format '{{.Names}} | {{.Status}}'
EXPECTED RESULT
open-webui | Up ...
PASS container open-webui อยู่สถานะ Up
05

Open GUI & Validate

พิมพ์ URL จากเครื่อง DGX Spark แล้วเปิดจาก Browser ใน LAN เดียวกัน

COMMAND — copy / paste
DGX_IP=$(ip route get 1.1.1.1 | awk '{print $7; exit}')
echo "http://$DGX_IP:8080"

curl --retry 20 --retry-connrefused --retry-delay 2 \
-s -o /dev/null -w "HTTP %{http_code}\n" \
http://127.0.0.1:8080
EXPECTED RESULT
http://192.168.x.x:8080 HTTP 200
PASS เปิด URL → สร้าง admin account → เลือก gemma4:26b-a4b-it-qat → Chat ได้

Troubleshooting

สไลด์สำรอง — ใช้เมื่อขั้นใดไม่ผ่าน แล้วรันขั้นนั้นซ้ำ

COMMAND — copy / paste
systemctl status ollama --no-pager
journalctl -u ollama -n 50 --no-pager
docker logs --tail 50 open-webui
docker rm -f open-webui
resolvectl query registry.ollama.ai
EXPECTED RESULT
active (running) Ollama service log Open WebUI log redeploy → step 04 DNS resolves OK
FIX แก้แล้วรันขั้นตอนนั้นซ้ำ · ยังไม่ผ่าน → sudo systemctl restart ollama แล้วเริ่มจากขั้น 02
